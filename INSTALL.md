# Dotfiles

Personal config for nvim, tmux, Hyprland, kitty/foot, fish/zsh, starship, and more.

Managed with [GNU Stow](https://www.gnu.org/software/stow/).

## Quick Start

```bash
# Install stow (Arch)
sudo pacman -S stow

# Clone (if using git) or navigate to repo
cd ~/dotfiles

# Backup existing configs, then deploy
make backup && make
```

## Manual Stow

```bash
# Deploy everything
stow --target=$HOME home

# Or selectively
stow --target=$HOME home/.config/nvim
```

## Per-machine Setup

Some paths and configs are machine-specific:

1. **Git `[safe]` directories** — set on each machine:
   `git config --global --add safe.directory /path/to/repo`

2. **Git shared config include** — uncomment in `.gitconfig` and point to your shared file

3. **Google Cloud SDK** — install separately; shell rc files source it conditionally

4. **Monitor config** — `hypr/monitors.conf` is machine-specific (generated by nwg-displays)

5. **Nvim LSP/formatters** — installed via Mason on first run
